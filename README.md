# Rainfall Avenue

A relaxing, first-person 3D rainy-city walk with original lo-fi music — made for big screens,
comfortable on phones. Wander a West Village–inspired New York neighbourhood (plus Chicago,
Los Angeles, Miami and a stylised Kyoto), or sit back while a scenic stroll walks for you.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

See `docs/` (coming with the next commits) for architecture notes.
