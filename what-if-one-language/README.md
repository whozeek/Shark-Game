# What If… Everyone Suddenly Spoke the Same Language?

- `what-if-one-language.mp4` – 66-second 2D animation (1080p, narrated, music, captions)
- `what-if-one-language-tiktok.mp4` – vertical 1080×1920 cut for TikTok / Reels

Built the same way as `../what-if-no-guns`: `script.json` + `tts.py` (voiceover), `lib.js` + `scenes.js` + `index.html` (animation, open `index.html` to preview), `render.js` (frames → video), `audio.py` (music and mix), `tiktok.py` (vertical cut).
